# TISSEC — Tamale Islamic Science Senior High School

Static website for Tamale Islamic Science Senior High School (TISSEC).

**Live site:** https://tissec-phi.vercel.app

## Pages
- **Home** (`index.html`)
- **About** (`about.html`)
- **Courses** (`courses.html`)
- **Gallery** (`gallery.html`) — school crest, NSMQ team, contests and events
- **Contact** (`contact.html`)

## Tech stack
HTML and CSS, deployed on Vercel.

## Running locally
No build step — clone the repo and open `index.html` in a browser.
